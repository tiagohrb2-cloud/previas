Rota Mídia

Por onde sua marca rodou

Rotas reais gravadas pelo GPS do celular de cada motoboy, com a bag ligada. Escolha uma bag ou um anunciante para ver só o trajeto dele.

Estes são dados de demonstração. Assim que os motoboys gravarem as primeiras rotas, o mapa passa a mostrar os trajetos de verdade.
